# NewsAlpha

NewsAlpha is a point-in-time, sentiment-aware portfolio research platform.

The project investigates whether financial-news sentiment improves out-of-sample, risk-adjusted portfolio performance after transaction costs.

## Current Status

The project is under active development.

### Milestone 1

- Project structure
- Reproducible Python environment
- Portfolio accounting
- Baseline strategies
- Performance metrics
- Automated tests

## Research Principles

- Prevent look-ahead bias
- Evaluate models out of sample
- Compare against simple baselines
- Include realistic transaction costs
- Preserve experiment reproducibility
- Report unsuccessful experiments honestly
